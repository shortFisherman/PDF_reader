# 提案：模型配置模板

## 动机

当前项目存在以下配置相关问题：

1. **缺少配置模板**：`config.toml` 被 `.gitignore` 排除，新用户克隆仓库后没有可参考的配置文件模板
2. **API Key 路径不明确**：虽然 README 中有说明，但没有示例文件，用户不清楚 `config.toml` 的结构和 API Key 的填写位置
3. **模型配置缺乏文档**：`[deepseek]` 配置段没有注释说明各项含义，用户无法自行修改模型供应商、base_url 等参数

## 目标

- 创建 `config.example.toml` 模板文件，包含详细的中文注释
- 更新 README 引导用户从模板复制配置

## 范围

- 仅涉及配置文件的文档和模板补充
- 不修改任何代码逻辑
- 不增加新能力
